# Autocart Mod

A Fabric mod for Minecraft 1.20.4 that automatically places minecarts when rails are placed. This mod simplifies the process of creating minecart tracks by automatically placing minecarts on newly placed rails, saving time and effort for players.

## Installation

1. Install Fabric Loader 0.14.21 for Minecraft 1.20.4.
2. Download the mod jar from the releases page.
3. Place the jar in your mods folder.

## Usage

Simply place rails in the world. Minecarts will be automatically placed on the rails.
